# anopheles/homebrew-tap

Homebrew casks for [navigo](https://github.com/anopheles/navigo), a
keyboard-driven terminal client for Navidrome and Subsonic servers.

```sh
brew install anopheles/tap/navigo
```

`Casks/navigo.rb` is written by navigo's release workflow when a release
is published; don't edit it here.
